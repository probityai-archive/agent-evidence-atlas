Choose the pin for your task

  • Install or integrate: use a component’s reviewed guide, then keep the exact package version or source commit its recipe selects. A guide can deliberately use an older release.
  • Repeat a tested installation: use the recipe’s recorded source, environment, command and retained output. A release number alone is not an install result.
  • Cite or replay a result: retain the source and artifact digests in that result. Lab records, historical examples and citation snapshots do not move when a new release appears.
